# Profile setup & maintenance

## What this repository does

- `README.md` is the public profile page for `goutham2442-star`.
- `assets/profile-banner.svg` is a custom SVG banner with animated accents.
- `.github/workflows/snake.yml` generates contribution-snake SVGs daily and publishes them to the `output` branch.
- `.github/workflows/activity.yml` refreshes recent public GitHub activity every six hours.

## Enable Actions

1. Open **Settings → Actions → General** in this repository.
2. Under **Workflow permissions**, select **Read and write permissions** and save.
3. Open **Actions** and enable workflows if GitHub asks.
4. Run **Generate contribution snake** manually once. It creates/publishes the `output` branch.
5. Run **Update profile activity** manually once and inspect the result.

GitHub's scheduled workflows may run late during busy periods. The external statistics cards can be cached or temporarily unavailable; they are not controlled by this repository.
